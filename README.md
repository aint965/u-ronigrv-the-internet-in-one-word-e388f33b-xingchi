## What it does

`main.ts` writes exactly one word to `<output dir>/entry.txt` — no trailing
newline, no extra text:

```
enshittification
```

Run it with Node 22:

```sh
node main.ts /output
```

## Why this word

*Enshittification* is the slow decay of every platform you once loved: first
great for users, then great for advertisers, then great for shareholders, and
finally bad for everyone. It is funny because it sounds like a joke and true
because it describes the whole internet at once — not one app, not one mood,
but the shared arc of the entire web. It lands in one beat and surprises:
nobody's first guess, everybody's second nod.
